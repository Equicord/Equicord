# BetterPollDetails

A plugin that shows poll percentages and vote counts before voting or expiration without disabling the ability to vote.

## Preview

| Default Discord Poll | With BetterPollDetails |
| :---: | :---: |
| ![Default Discord Poll](https://github.com/user-attachments/assets/e9d971f7-830c-4557-8794-722d89f3f620) | ![With BetterPollDetails](https://github.com/user-attachments/assets/eee4152d-2fff-4b98-89ca-ee80bf9064de) |
| Results hidden until you vote or the poll ends | Percentages and vote counts shown while voting remains interactive |
