# DuplicateCategory

Adds a **Duplicate Category** option to the category context menu.

## Features

- Right-click any category to duplicate it
- Choose a name for the new category
- Toggle whether to copy permissions from the original category or use default server permissions
- Requires the `Manage Channels` permission
